# FCC Claude Android

Aplicativo Android nativo em Kotlin e Jetpack Compose.

## Requisitos

- JDK 17
- Android SDK com Android 36 (compile SDK)

## Executar

```sh
./gradlew assembleDebug
```

No Termux, se necessário, execute o wrapper com `sh ./gradlew assembleDebug --console=plain`.

## Testes

```sh
./gradlew test
```
